Request Data Flow

User interacts with a view
A view (e.g. Dashboard.vue) reads the active filters from the shared useFilters() composable — a singleton holding four reactive refs.
Filters become a request
getCurrentFilters() maps UI state to an object, which api.js turns into a query string via URLSearchParams, omitting any filter set to all.
HTTP call to FastAPI
axios issues a request to http://localhost:8001/api/…. CORS middleware (allow-all) lets the port-3000 origin through.
In-memory filtering
The endpoint runs apply_filters() (warehouse / category / status) and filter_by_month() (month or Q1–Q4-2025) over the Python lists loaded at startup. Original data is never mutated.
Validation & response
Results are validated against a Pydantic response_model and returned as JSON.
Reactive render
The view stores raw data in refs; computed properties derive totals, charts, and tables that re-render automatically.

The Four-Filter System

Shared globally through useFilters.js and passed to endpoints as query params. Inventory has no time dimension, so it ignores the period filter.
